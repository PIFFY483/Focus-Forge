# Focus Forge Summary: A simple third-person camera utility with lock-on mechanics.

Description:

Focus Forge is a lightweight mod that adds a shoulder-camera offset and an entity lock-on system.

This project was built to provide a more focused perspective during combat and exploration. It’s not meant to be a massive game-changer, just a cleaner way to look at the world.

The code is open for anyone who wants to take a look or build upon it.
